# Store Listing Draft

## Product Positioning

`Currency Converter` helps you convert between currencies quickly with live exchange rates. Add the currencies you need, enter an amount, and see updated values across the list.

## Short Description

Convert currencies instantly with live exchange rates.

## Full Description

Convert money between currencies in seconds.

`Currency Converter` is a simple multi-currency converter with live exchange rates. Add the currencies you care about, type an amount, and instantly see the converted values. Drag to reorder currencies, swipe to remove ones you no longer need, and use the built-in calculator when you need a quick calculation.

### What it does well

- Live fiat exchange rates
- Selected cryptocurrency prices (Bitcoin, Ethereum, Tether)
- Multiple currencies on one screen
- Drag-and-drop reordering
- Built-in calculator
- Light / dark / system appearance
- Works with cached rates when the network is unavailable after the first successful update

### Best for

- Travelers comparing prices
- Everyday currency checks
- Quick crypto-to-fiat glances
- Anyone who switches between several currencies often
